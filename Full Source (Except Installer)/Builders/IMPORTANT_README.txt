=== IMPORTANT README — راهنمای فایل‌های build_*.bat ===

## پیش‌نیاز
این ۶ فایل bat به «Dev-C++» (نسخهٔ Embarcadero) نیاز دارن که روی کامپیوتر
شما نصب باشه. این خودش Dev-C++ نیست — فقط از کامپایلری که Dev-C++ نصب
می‌کنه (TDM-GCC-64) استفاده می‌کنه.

## مسیر کامپایلر که همین الان داخل هر ۶ فایل تنظیم شده
```
C:\Program Files (x86)\Embarcadero\Dev-Cpp\TDM-GCC-64\bin\g++.exe
```
این مسیر داخل خط `set GPP32=...` یا `set GPP64=...` هرکدوم از فایل‌ها هاردکد شده.

## اگه یه روز این مسیر عوض شد (کامپیوتر جدید، نصب مجدد Dev-C++، و غیره)

**مرحله‌به‌مرحله برای پیدا کردن مسیر جدید:**
1. Dev-C++ رو باز کنید
2. از منو بالا: **Tools → Compiler Options**
3. در پنجرهٔ باز شده، تب **"Settings"** یا کنار اسم کامپایلر، دنبال فیلدی
   بگردید که مسیر پوشهٔ نصب کامپایلر رو نشون می‌ده (معمولاً یک آیکون سه
   نقطه `...` کنارش هست)
4. اون مسیر یک پوشه‌ست (مثلاً `...\TDM-GCC-64`)؛ شما باید به انتهاش
   `\bin\g++.exe` اضافه کنید

**بعد از پیدا کردن مسیر جدید:**
هر ۶ فایل `.bat` رو با Notepad باز کنید و خط زیر رو پیدا کنید:
```
set GPP32="مسیر قدیمی..."
```
یا
```
set GPP64="مسیر قدیمی..."
```
و مسیر قدیمی رو با مسیر جدید (بین دو گیومه) جایگزین کنید. همین.

## نکتهٔ مهم دربارهٔ نسخهٔ ۳۲‑بیتی

چون شما فقط یک کامپایلر (`TDM-GCC-64`) دارید، فایل‌های `_x86.bat` هم از
**همون** کامپایلر استفاده می‌کنن، ولی با فلگ اضافهٔ `-m32` که ازش می‌خوان
به‌جای خروجی ۶۴‑بیتی، خروجی ۳۲‑بیتی بسازه. TDM-GCC واقعی (که Embarcadero
Dev-C++ استفاده می‌کنه) معمولاً این قابلیت رو داره.

**اگه فایل‌های `_x86.bat` با این خطا شکست خوردن:**
```
cannot open linker script file ldscripts/i386pe.x
```
یعنی این نسخهٔ خاص TDM-GCC-64 شما این قابلیت (multilib) رو نداره. در این
صورت باید یک کامپایلر **جدا و مخصوص ۳۲‑بیتی** پیدا/نصب کنید (مثلاً یک
پکیج قدیمی‌تر MinGW ۳۲‑بیتی)، و مسیرش رو در `GPP32` بذارید — و در این
حالت خط `-m32` رو از فایل bat حذف کنید (چون یک کامپایلر ۳۲‑بیتی‌مخصوص،
خودش همیشه فقط خروجی ۳۲‑بیتی می‌ده، نیازی به فلگ اضافه نداره).

## یادآوری برای Service و Broker (نه برای LicenseCheck)
قبل از اجرای `build_Service_*.bat` یا `build_Broker_*.bat`، حتماً باید
`CoordinatorIdentityPrivate.h` و `TransportKeyPrivate.h` رو موقتاً از
پوشهٔ امن `01_DO_NOT_UPLOAD_TO_GITHUB` کنار سورس‌ها کپی کنید (خود فایل
bat هم اگه این‌ها رو نبینه، با پیام خطای واضح متوقف می‌شه). بعد از build،
حتماً دوباره حذفشون کنید.
