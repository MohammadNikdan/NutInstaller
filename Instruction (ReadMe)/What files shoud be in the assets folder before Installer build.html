مرجع کامل — پیش از Build نصب‌کننده

دقیقاً چه فایل‌هایی باید در Assets/ باشند؟

این صفحه فهرست کامل ۱۲ فایلی است که NutriculaInstaller.csproj پیش از build نیاز دارد، به‌همراه این‌که هرکدام دقیقاً کجا (تحت چه شرطی) روی کامپیوتر مشتری کپی می‌شوند.

هرگاه یکی از این فایل‌ها را عوض کردید (نسخهٔ جدید EA، کلید جدید، Manifest جدید)، باید همان فایل را اینجا هم جایگزین کنید و دوباره Installer را build بگیرید — خود Installer فایل‌های قدیمی را به‌روزرسانی نمی‌کند، آن‌ها را در build خودش هاردکد (Embedded Resource) می‌کند.

پروژهٔ Installer\ └── Assets\ ├── Nutricula.ex4 ├── Nutricula.ex5 ├── NutriculaLicenseCheck32.dll ├── NutriculaLicenseCheck64.dll ├── MachineId32.dll ├── MachineId64.dll ├── NutriculaLicenseService32.exe ├── NutriculaLicenseService64.exe ├── NutriculaLicenseBroker32.exe ├── NutriculaLicenseBroker64.exe └── manifest.txt روی کامپیوتر مشتری، بعد از نصب: اگر ترمینال MT4 پیدا شود (به ازای هر نصب MT4 جدا): <ترمینال>\MQL4\Experts\Nutricula.ex4 <ترمینال>\MQL4\Libraries\NutriculaLicenseCheck32.dll <ترمینال>\MQL4\Libraries\MachineId32.dll اگر ترمینال MT5 پیدا شود (به ازای هر نصب MT5 جدا): <ترمینال>\MQL5\Experts\Nutricula.ex5 <ترمینال>\MQL5\Libraries\NutriculaLicenseCheck64.dll <ترمینال>\MQL5\Libraries\MachineId64.dll همیشه، یک‌بار، سراسری (صرف‌نظر از تعداد/نوع ترمینال‌ها): %ProgramFiles%\Nutricula\LicenseService\ NutriculaLicenseService.exe ← از Service32 یا Service64، بر اساس بیت‌بودن Windows میزبان NutriculaLicenseBroker.exe ← از Broker32 یا Broker64، بر اساس بیت‌بودن Windows میزبان MachineId32.dll یا MachineId64.dll ← بر اساس همان بیت‌بودن Windows میزبان Nutricula.ex5 Nutricula.ex4 NutriculaLicenseCheck32.dll NutriculaLicenseCheck64.dll manifest.txt
نکتهٔ مهم دربارهٔ بیت‌بودن: برای Service/Broker/MachineId که در پوشهٔ Coordinator نصب می‌شوند، معیار انتخاب ۳۲ یا ۶۴ بودن، بیت‌بودن خود Windows میزبان است (Environment.Is64BitOperatingSystem) — نه بیت‌بودن MT4/MT5 و نه بیت‌بودن خود Installer (که همیشه ۳۲‑بیتی اجرا می‌شود ولی این API واقعی بودن سیستم‌عامل را درست تشخیص می‌دهد حتی وقتی زیر WOW64 اجرا شود).
